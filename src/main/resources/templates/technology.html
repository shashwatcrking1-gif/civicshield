CORE BACKEND

Java 17 & Spring Boot 3

Strong typing, memory safety, and battle-tested multithreading. Implements layered architecture (Controller → Service → Repository) with constructor injection and bean validation.

SERVER RENDERING

Spring MVC + Thymeleaf

Zero client-side bundle load failures during catastrophic mobile connectivity drops. Reusable fragments for modular, clean, and accessible UI rendering.

DEFENSE IN DEPTH

Spring Security & RBAC

Granular URL authorization with CSRF protection, BCrypt password hashing, and role checks (ADMIN, AUTHORITY, EMERGENCY_SERVICE, HOSPITAL).

CORE ALGORITHM

Built-in Cascade Engine

Propagates crisis weights down the 6-node chain with sub-millisecond calculation speeds. Operates unconditionally without external dependencies.

AI INTEROP

WebClient Python AI Bridge

Optionally talks to Python deep learning services over reactive WebClient. If the AI service times out or is offline, it seamlessly falls back to the Java engine.

DATA PERSISTENCE

Dual-Profile JPA Persistence

Spring Data JPA with Hibernate. The demo profile runs entirely in-memory using H2 with automated Chennai seed data; prod connects to PostgreSQL/PostGIS.

Zero-Failure Resiliency Architecture

Even during server power disruptions, the built-in deterministic cascade engine ensures emergency prediction services continue functioning.
